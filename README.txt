Save the gym walkthrough video in this folder as:

    gym-tour.mp4

The "Take a Look Inside" section on index.html will pick it up automatically.
Until the file is added, that section shows the gym photo as a poster image.

Tips:
- MP4 (H.264) plays everywhere.
- Keep it under ~20 MB so the page stays fast — 30 to 60 seconds is plenty.
